# くるま実験ラボ

サスペンションと空力を、パーツの組み合わせと速度を変えながら試せるブラウザ用シミュレーターです。

- 車種：コンパクトハッチ／クーペ
- サスペンション：スプリング、ダンパー（減衰力調整式あり）、スタビライザー、タイヤ
- 空力：リップ／スプリッター、リアスポイラー／GTウイング（角度調整）、アンダーパネル、ディフューザー
- 速度 0〜250 km/h、路面（段差・うねり・荒れた路面・フラット）

## 使い方

`index.html` をブラウザで開くだけで動きます。GitHub Pages で公開する場合は
Settings → Pages → Branch を `main` / `(root)` にしてください。

## 計算について

学習用の簡易モデルです（クォーターカーモデル＋Cd/Cl による空力計算）。
実車のセッティングにそのまま使える数値ではありません。
