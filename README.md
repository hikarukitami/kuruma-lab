# くるま実験ラボ

サスペンション・アライメント・空力を、パーツの組み合わせと速度を変えながら3Dで試せるブラウザ用シミュレーターです。

## できること

- 車種：コンパクトハッチ（FF）／クーペ（FR）
- 車両：エンジン、軽量化、ホイール、タイヤ
- サスペンション：キット4種、前後のばねレート・車高・減衰力（伸び／縮み）、前後スタビライザー
- アライメント：前後のキャンバー・トー
- 空力：リップ／スプリッター、カナード、ボンネットダクト、サイドスカート、リアスポイラー／GTウイング（角度・ガーニーフラップ）、アンダーパネル、ディフューザー
- 走らせ方：速度 0〜250 km/h、横風、路面6種、直進／定常円旋回／スラローム／ブレーキ／加速
- 表示：3D（気流・圧力分布・力と4輪荷重・透視）、グラフ7種、仕様の保存と比較

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。
GitHub Pages で公開する場合は Settings → Pages → Branch を `main` / `(root)` にしてください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `js/data.js` | 車両データ・パーツデータ（数値を変えたいときはここ） |
| `js/physics.js` | 計算（車両モデル、空力、コーナリング、7自由度シミュレーション） |
| `js/view3d.js` | 3D表示 |
| `js/charts.js` | グラフ |
| `js/ui.js` | 操作・数値表示・保存比較 |
| `vendor/three.bundle.js` | 3D描画ライブラリ three.js（MITライセンス） |

## 計算について

学習用の簡易モデルです。車両・パーツの数値や価格は一般的な目安から決めた値で、
気流と圧力分布の表示は車体形状から作った簡易表示です（CFDや風洞試験の結果ではありません）。
実車のセッティングにそのまま使える数値ではありません。
